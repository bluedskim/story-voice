# 목소리 녹음 가이드

잠자리 동화용 목소리 샘플을 녹음할 때 참고해요.

## 준비

- 조용한 방, 에어컨·선풍기 소리를 줄여요.
- 마이크는 입에서 15~20cm 정도 떨어져요.
- 폰 녹음 앱이나 QuickTime으로 충분해요.

## 어떻게 읽을까

- 잠들기 직전에 아이에게 읽듯, **천천히** 또박또박 읽어요.
- **10~30초**, 한국어 **한 문단**이면 충분해요.
- 속삭이지 말고, 평소 대화보다 조금 부드럽게요.
- 녹음한 문장과 **똑같은 받아쓰기**를 `data/voice/reference.txt`에 넣어요.

## 파일로 저장

Mac에서 변환 예시 (24kHz 모노, 모델 입력에 맞춤):

```bash
ffmpeg -i 원본.m4a -ar 24000 -ac 1 data/voice/reference.wav
```

`reference.wav`와 `reference.txt`는 git에 올리지 마세요. 이 집 목소리예요.
